# 附录 G 术语表

本附录汇总全书术语，一份给一句话定义；按全书统一口径（见 `asset/style-guide.md` §7）撰写。分类列出，方便按需查阅。

---

## G.1 容器与加载

| 术语 | 定义 |
|---|---|
| **GGUF** | llama.cpp 生态使用的模型容器格式：以"magic + version + tensor_count + kv_count"开头，依次是 KV 元数据、tensor_infos 目录和数据块。 |
| **GGML（旧格式）** | GGUF 的前身，已不再支持；GGUF 是其替代品（第 3 章）。 |
| **容器（container）** | 规定"元数据 + 张量目录 + 张量数据"如何排列的文件格式，不关心张量数据的具体类型。 |
| **张量（tensor）** | 多维数组；在本书语境里指模型中的权重矩阵，如 `attn_q.weight`。 |
| **元数据（metadata）** | 用键值对（key-value）存储的描述信息，如架构名、词表大小、上下文长度。 |
| **KV 键值对** | GGUF 元数据的最小单元：key（长度前缀字符串）+ value_type + value（第 3 章）。 |
| **tensor_infos[]** | GGUF 中的张量目录：每个张量的名字、维度、量化类型、数据偏移。偏移相对数据段起点（第 3 章）。 |
| **offset** | tensor_infos 里的数据偏移，是"相对数据段起点"而不是"相对文件头"（第 3 章）。 |
| **alignment（对齐）** | GGUF 默认 32 字节（`general.alignment`）；数据段起点对齐到它的整数倍，保证 mmap 后每张量对齐（第 3 章）。 |
| **mmap（内存映射）** | 把磁盘文件映射进进程虚拟内存，"读文件"变成"读内存"，避免整块拷贝；GGUF 零拷贝加载的基础（第 3 章）。 |
| **POD（Plain Old Data）** | 纯数据型结构体，无构造函数/虚函数/指针，内存布局与字节序列一一对应；量化块必须是 POD（第 3、4 章）。 |
| **endianness（字节序）** | 多字节整数高位在前（大端）还是低位在前（小端）；GGUF 默认小端（第 3 章）。 |
| **nibble（半字节）** | 4 bit；一个 `uint8_t` 可拆成两个 nibble，Q4_0 等格式的打包基础（第 4 章）。 |

## G.2 量化结构与参数

| 术语 | 定义 |
|---|---|
| **量化（quantization）** | 用更少比特表示数值；本书指把浮点权重映射到整数量化码与少量尺度参数（第 1、2 章）。 |
| **反量化（dequantization）** | 推理时把压缩后的量化块还原成浮点数（第 4 章起各格式）。 |
| **bit/weight（bpw）** | 每权重平均比特数 = 块字节数 × 8 ÷ 每块权重数。包含尺度、最小值、打包的开销，不等于码位宽（第 1 章）。 |
| **块（block）** | 共享一组量化参数（如一个尺度）的最小权重集合；Q4_0 是 32 值的块（第 4 章）。 |
| **超级块（super-block）** | K-quants 的 256 值高层次单元，承载全局尺度 `d` 与全局最小值尺度 `dmin`（第 6 章）。 |
| **子块（sub-block）** | 超级块内部的 32 值（Q4_K/Q5_K）或 16 值（Q2_K/Q3_K/Q6_K）单元，各自有自己的尺度/最小值（第 6 章）。 |
| **尺度（scale，`d`）** | 块级缩放因子，把量化码映回浮点幅度；通常存为 FP16（第 2、4 章）。 |
| **dmin / 最小值尺度** | K-quants 全局的最小值缩放因子，配合子块最小值恢复非对称偏移（第 6 章）。 |
| **最小值（min，`m`）** | 非对称量化的偏移项，Q4_1 显式存、Q4_K 的每个子块单独估计（第 5、7 章）。 |
| **零点（zero-point，`z`）** | 非对称参量化里的第三种写法，显式存零点；GGUF 主流用尺度+最小值而非显式零点（第 1 章）。 |
| **量化码/码（quant code，`q`）** | 量化后落在码字范围内的整数；Q4_0 的 `q∈[0,15]`（第 4 章）。 |
| **clamp（夹取）** | 把越界的量化码强制限制在码字范围内；被夹取的值产生"饱和误差"而非舍入误差（第 2 章）。 |
| **饱和误差（saturation error）** | 离群值被 clamp 到边界码产生的误差，与舍入误差性质不同（第 2 章）。 |
| **尺度失配误差（scale mismatch error）** | 块内分布不均匀时，单一尺度无法同时适配大值与小值导致的误差；Q4_0 的主要误差来源（第 2、4 章）。 |

## G.3 层叠量化策略

| 术语 | 定义 |
|---|---|
| **K-quants（K 系列量化）** | 以"256 值超级块 + 两级尺度"为骨架的格式族：Q2_K、Q3_K、Q4_K、Q5_K、Q6_K（第 6 章起）。 |
| **nibble 打包 / lo-hi split** | 一个字节装两个 4-bit 码的布局：低 nibble 与高 nibble 分属不同（偏移 16 的）权重（第 4 章）。 |
| **高位平面（high-bit plane）** | Q5_K/Q6_K 中独立存储的额外比特，与低位主体合成更高位宽的码（第 5 位/6 位，第 8、9 章）。 |
| **`_S`/`_M`/`_L` 后缀** | 文件级"混合策略"编号：描述按张量敏感度分配类型的激进程度，不是编码格式（第 14 章）。 |
| **Q4_K_M** | 最常见的混合策略：Q4_K 主体 + Q6_K 输出层 + F32 归一化；`_M` 不是一种 `ggml_type`（第 3、14 章）。 |
| **敏感度（sensitivity）** | 某张量/某块量化误差对最终输出的影响程度；决定它在混合策略中的位宽（第 14 章）。 |

## G.4 码本与重要性加权

| 术语 | 定义 |
|---|---|
| **码本（codebook / grid）** | IQ 系列使用的查找表：每个表项是一个小整数向量，反量化时用索引直接查表，而非算术展开（第 11 章）。 |
| **grid（格点）** | 码本表项可达的重建点集合；IQ 系列用非线性格点匹配权重分布（第 11 章）。 |
| **imatrix（重要性矩阵）** | 校准阶段测得的逐权重重要性加权（由激活幅度决定），量化时按它加权误差预算（第 2、11 章）。 |
| **加权最小二乘** | \(\min\sum_i \alpha_i (x_i-\hat x_i)^2\)：把误差向"对输出影响大"的权重倾斜，而非均匀最小化 MSE（第 2 章）。 |
| **calibration / 校准数据** | 用于测 imatrix（及部分量化决策）的文本/激活样本，反映目标领域的统计（第 11、15 章）。 |
| **IQ 系列** | 依赖 imatrix 与码本的超低位宽格式族：IQ2_XXS、IQ2_XS、IQ2_S、IQ3_XXS、IQ3_S、IQ1_S、IQ1_M、IQ4_NL、IQ4_XS（第 11 章）。 |
| **IQ4_NL** | 与 Q4_0 同布局但查非线性格点 `kvalues_iq4nl[16]` 的格式；同 bpw 高质量（第 11 章）。 |

## G.5 三值量化

| 术语 | 定义 |
|---|---|
| **三值量化** | 权重被约束到 \(\{-d, 0, +d\}\) 的极限压缩；核心问题是零的位置如何编码（第 13 章）。 |
| **trit** | 三值单元，可取 −1/0/+1；信息熵约 \(\log_2 3 ≈ 1.585\) bit（第 13 章）。 |
| **base-3 编码** | 用三进制数字打包 trit 序列的编码方式，每个字节可装 5 个 trit（PTQ1_0，第 13 章）。 |
| **稀疏三值** | 强制每 N 个权重中恰好若干为零的三值格式（STQ1_0 为 3:4 稀疏，第 13 章）。 |
| **stride-16 分组** | 把 64 值块内相隔 16 的权重（\(w_0,w_{16},w_{32},w_{48}\)）分为一组，使 SIMD 查表无需重排（第 13 章）。 |
| **STQ1_0** | 3:4 稀疏三值格式；每 4 权重 1 零、32 模式、5 bit/组；stride-16 分组、NEON 友好（第 13 章，⚠ fork/PR）。 |
| **PTQ1_0** | 稠密三值格式，base-3 编码；**Hadamard 折叠是必需变换**（第 13 章，⚠ fork/PR）。 |
| **Hadamard 折叠** | 把权重先做 Hadamard 变换再存储的方式；推理必须应用激活侧逆变换，否则 logits 完全错误（第 13 章）。 |
| **1.58-bit / TQ 系列** | 三值的约等位宽口径；TQ1_0（1.6875 bpw）/TQ2_0（2.0625 bpw）已入主线（第 13 章）。 |
| **阈值效应（threshold effect）** | 三值格式的劣化不是平滑曲线，而是某位宽/模型组合下任务能力的断崖式下降（第 2、13 章）。 |

## G.6 质量与性能评估

| 术语 | 定义 |
|---|---|
| **PPL（perplexity，困惑度）** | 语言模型预测能力指标，越低越好；量化后 PPL 增幅描述质量损失（第 2、4 章）。 |
| **KL（KL 散度）** | 量化模型与参考模型在 logits 分布上的差异；IQ/三值格式更常用它而不只看 PPL（第 2、11 章）。 |
| **MSE（均方误差）** | 重建值与原值的平均平方差，格式调试用（第 2 章）。 |
| **TTFT（首 token 延迟）** | 从请求到第一个输出 token 的延迟；端侧可用性的关键指标（第 17 章）。 |
| **P95 延迟** | 延迟的第 95 百分位，反映尾部/抖动；端侧报纸不只平均 tok/s（第 17 章）。 |
| **roofline 模型** | 用"算术强度—可达性能"的分析模型；说明自回归解码是带宽受限而非算力受限（第 1、17 章）。 |
| **cold start（冷启动）** | 模型首次加载（通常 mmap 首次缺页）到可推理的延迟（第 1 章）。 |
| **vec_dot** | 在量化块上直接做点积的矩阵乘内核，避免先整块反量化；IQ 查表与 K-quants 算术路径在此分叉（第 16 章）。 |
| **后端（backend）** | 具体执行矩阵乘的硬件路径：CPU-SIMD、Metal、CUDA、Vulkan 等；格式支持度因后端而异（第 16、17 章）。 |

## G.7 工具与生态

| 术语 | 定义 |
|---|---|
| **convert_hf_to_gguf.py** | llama.cpp 的 HF→GGUF 转换脚本；只做容器转换与张量命名映射，不量化（第 15 章）。 |
| **llama-quantize** | llama.cpp 量化工具：`llama-quantize in-f16.gguf out.gguf Q4_K_M`，`Q4_K_M` 是策略名（第 15 章）。 |
| **llama-imatrix** | 生成重要性矩阵的工具：`-m f16 -f calib.txt -ngl 99 -o imatrix.dat`（第 11、15 章）。 |
| **llama-perplexity** | PPL/KL 评测工具；`--kl-divergence-base` 指定参考模型（第 15、18 章）。 |
| **gguf-py** | 官方的 Python GGUF 库；提供 `GGUFReader`/`GGUFWriter`/`dequantize` 等（第 3 章、附录 D）。 |
| **type_traits[]** | ggml.c 里的类型特征表：把 type id 映射到块大小、类型大小、量化/反量化函数指针（第 3、16 章）。 |
| **type id（类型编号）** | 每个 `ggml_type` 的全局整数编号；编号冲突会导致"同一 id 不同格式"（第 3、13、19、20 章）。 |
| **fork/PR 阶段** | 尚未合入 llama.cpp 主线的功能/格式；可读文件名 ≠ 当前构建能正确分派（第 13、19、20 章）。 |

## G.8 使用说明

- 术语定义采用**全书统一口径**（block、super-block、子块、尺度等），与各章正文一致。
- 涉及数字的条目（bpw、字节数）均按主线源码核实；三值格式标注 ⚠ fork/PR。
- 按需检索：找格式看 G.2–G.5，找工具命令看 G.7，端侧评估看 G.6。
